# ProjetWebAgency – Code&Craft

✨ **Agence hybride** : nous accompagnons à la fois les **artisans** dans leur digitalisation et les **startups tech** dans leur image de marque.  
Ce projet présente notre site vitrine, développé en **HTML, Sass et JavaScript POO**, avec une identité visuelle premium et moderne.

---

## 🚀 Technologies utilisées
- **HTML5** : structure sémantique et accessible
- **Sass (SCSS)** : architecture modulaire avec `@use` 
- **JavaScript POO** : composants dynamiques (carousel, interactions)
- - **PHP (PDO)** : gestion sécurisée du formulaire de contact
- **MySQL** : base de données pour stocker les messages
- **Git & GitHub** : workflow pro avec branches `main` et `dev`
